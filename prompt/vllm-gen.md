# vllm_gen.py

The utility vllm_gen.py does an analysis of an image. Then, the utility gets the text from the image.

The utility has 4 arguments:

- --model: The AI model that you use.
- --image: The path to the image.
- --prompt: The prompt for the AI.
- --max-tokens: The limit for the number of tokens.
- --output: The path to the output file. Default is output.md.
